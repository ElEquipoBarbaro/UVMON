UVG Classroom 2021 Package

Versión objetivo:
Unity 2021.3.45f2

Qué incluye:
- Sprites y paneles tomados del tilemap del aula
- Script para preparar import settings
- Script para construir automáticamente el mapa del aula en Unity 2021

Ruta esperada:
Assets/UVGClassroom2021/

Cómo usar:
1. Copia la carpeta UVGClassroom2021 dentro de Assets de tu proyecto.
2. Abre Unity 2021.3.45f2.
3. Espera a que compile.
4. Ve al menú:
   UVG > 2021 > Prepare Imported Sprites
5. Luego:
   UVG > 2021 > Build Classroom Map

Qué construye:
- Cámara ortográfica 2D
- Piso base
- Secciones superiores del tilemap del aula
- Área inferior con pupitres
- Puerta básica

Notas:
- Está pensado específicamente para Unity 2021.3.45f2.
- La forma más segura de entregártelo sin correr Unity aquí fue como paquete "Assets" listo para arrastrar al proyecto.
- Si luego quieres, se puede hacer una segunda versión con:
  - colliders más finos
  - spawn del jugador
  - puntos de interacción
  - navegación por grid
